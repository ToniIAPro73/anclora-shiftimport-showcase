# Ejemplos sintéticos / Synthetic examples

> Todos los datos mostrados en este repositorio son ficticios y se utilizan exclusivamente con fines de demostración profesional.
> All data shown in this repository is fictional and used exclusively for professional portfolio demonstration purposes.

Estos archivos ilustran el **tipo de entrada** que el pipeline de ingestión
acepta y el **tipo de salida estructurada** que produce. No son fixtures del
producto real ni derivan de cuadrantes reales.

- `sample-roster.csv` — cuadrante mensual ficticio en formato tabular
  (persona ficticia, códigos de turno neutros: `M` mañana, `T` tarde,
  `N` noche, `L` libre, `V` vacaciones).
- `sample-shifts.json` — representación estructurada de turnos tras la
  revisión: fecha ISO, horas `HH:mm`, tipo de turno del registro neutro.

Notas:

- Las fechas son de un mes ficticio de demostración.
- Los nombres, empresas e identificadores son inventados.
- El formato exacto de entrada que acepta el producto real es más amplio;
  estos ejemplos son solo ilustrativos.
